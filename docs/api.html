bin_event(edges, *, lower=0.0, upper=np.inf, mode='contained')

Select entire bins inside a range, or bins intersecting it (explicit).

Bins are [0,e0), [e0,e1), ..., [e_last,inf). The tail is never assigned an invented finite distance. Boundaries alone cannot resolve probabilities within one bin; contained and overlap bracket that ambiguity.

Optimize all eligible pairs, or each row's best k eligible partners.

partners=None means weighted mean over all pairs. Integer k means each active row needs at least k candidate partners; selection can change during optimization. This is contact probability, not physical interaction energy.

hallucination_lab.steps

mutation_step

mutation_step(state, backend, controls, key)

Greedy single-position mutation proposals scored with the same model key.

Uses no gradients and can therefore optimize forward-only caller-defined scores via a custom backend. trials is controlled by controls['trials']. The entire evaluated design sequence is hard one-hot; fixed backend positions remain fixed. Native decoders must preserve identities under one-hot conversion and map each proposal to exactly one residue change. Unsupported encodings (for example, a conflicting prepared bias) are rejected, not inverted or bypassed. Without a decoder, raw categorical identity is assumed. This is a reference algorithm, not a performance claim.

hallucination_lab.assessment

paired_evaluate

paired_evaluate(backend, before_logits, after_logits, *, conditions, output=None)

Evaluate both endpoints with identical keys, controls, and backend.

Each condition is {name: str, key: [uint32, uint32], controls: dict}. Ordinary backend exceptions are recorded, not omitted. Always inspect ``all_valid`` before using the report. Unexpected interrupts propagate. No gradients are requested; AF2's consistent score mode may compute them internally. Endpoints are supplied explicitly, never selected from a run. ``output`` writes a JSON report exclusively and refuses to overwrite.

compare_evaluations

Compare values and raw gradients, retaining direction AND magnitude tests.

The normalized update uses sqrt(number of nonzero gradient rows) / L2 norm, matching the declared sequence-SGD convention. It is not a substitute for raw-gradient checks. Neither reference nor observed is assumed ground truth.

audit_backend

audit_backend(backend, logits, key, controls=None, *, reference=None, tolerances=None, output=None, strict=True)

Gate a point before using its optimization result in a loss study.

Checks repeated gradient evaluations, score vs gradient graph, and (where available) an independent native forward graph. An optional reference backend adds a paired comparison; it must implement the SAME intended objective and gradient semantics. Failing raises AFTER writing the JSON report. Forward/AD disagreement is numerical inconsistency, not proof that AD is wrong. Cost: two gradient calls plus score and optional probe/reference calls.

hallucination_lab.backends.af2

AF2

class AF2(self, *, sequence, objective, data_dir, protocol='hallucination', design_positions=None, model_name=None, model_names=None, recycles=0, model_options=None, prep_options=None, prepare=None, matmul_precision='highest', score_mode='consistent', numerical_guard=True)

Protocol preparation is delegated to ColabDesign; objectives are explicit.

sequence contains the mutable protein's starting sequence (binder sequence for protocol='binder'). design_positions are zero-based within that sequence. prep_options accepts ColabDesign prep_inputs options (e.g. pdb_filename, target_chain, binder_len). model_options accepts constructor options. The upstream model object is available for advanced preparation via prepare. Optional model_names loads a parameter bank. controls['model_index'] selects one model per evaluation (default 0); controls['recycles'] overrides recycles. Parameter values are dynamic JIT arguments. Recycles run on the host using native compiled single-pass functions; changing counts reuses those graphs. Prediction.native['losses'] and ['loss_weights'] expose the prepared native components, but only the explicit objective is optimized. Each evaluation starts from zero previous state; initial-guess/initial-atom modes and clear_prev=False are explicitly unsupported. score_mode='consistent' uses the gradient graph even for score-only calls, discarding its gradient. This avoids graph-dependent score/gradient values at the cost of a backward pass. 'forward' opts into native forward scoring. probe_forward() exposes that independent graph for numerical audits. numerical_guard=True additionally compares the final gradient graph's scalar with a native forward call at the same previous state and key. A mismatch raises NumericalAuditError; this is not a gradient correctness certificate. Forward-only scoring requires explicitly setting numerical_guard=False.

AF2.evaluate(self, logits, key, controls=None, *, gradient=True, prediction=False)
AF2.probe_forward(self, logits, key, controls=None)

Independent native forward graph for audits, not an AD correctness test. A mismatch with evaluate may expose graph-dependent numerical sensitivity. Ordinary finite differences of hard/STE outputs do not validate the STE.

AF2.sequence_from_logits(self, logits, controls=None)

Decode native hard identities (alpha * logits + prepared bias). alpha defaults to 1, matching evaluate's default controls. This is the native hard sequence, not the argmax of a raw/soft mixed pseudosequence. Fixed positions always retain the supplied starting identities.

hallucination_lab.backends.af3

AF3

class AF3(self, *, input_json, design_chain, objective, model_dir, design_positions=None, bucket=256, recycles=0, remat=True, configure=None, attention='xla', template_gradient=False, matmul_precision='highest', profile_mode='auto')

One designed protein chain in an otherwise arbitrary AF3 input.

Native AF3 JSON must contain inline MSA/template data, already prepared for inference. Positions are zero-based within design_chain. No diffusion backpropagation: full_prediction() is explicitly forward-only.

AF3.evaluate(self, logits, key, controls=None, *, gradient=True, prediction=False)
AF3.full_prediction(self, logits, key, controls=None, *, autotune=True, diffusion_key=None)

Forward-only structure prediction from the selected hybrid controls. With default controls, even one-hot logits represent a soft query; use predict_hard_sequence() for validation of a locked protein sequence. By default, Tokamax cache misses are tuned in a local configuration scope. Generic untuned kernels can exceed a GPU shared-memory limit. Tuning adds first-call cost and can change floating-point rounding; the scope is restored after this call and does not alter evaluate() or its gradients. Set autotune=False only with kernels already qualified for the device and shape.

AF3.predict_hard_sequence(self, sequence, key, *, autotune=True, diffusion_key=None)

Pass the complete designed chain including its fixed positions. The adapter rebuilds the hard atom carrier and reads its native token identities, MSA rows and profile directly. The result records the sequence, input representation and both keys. With no explicit diffusion key, the sampler uses fold_in(key, 1). The configured recycle and precision policies still apply.

Hybrid training defaults to profile_mode="auto". A verified query-only input keeps the profile and all effective query copies differentiable. With homologs, the native carrier profile is preserved and the original MSA query row is relaxed. Select "replace" for the previous unconditional profile replacement.

AF3.sequence_from_logits(self, logits, controls=None)

Decode the same carrier identities as evaluate, retaining fixed positions.
