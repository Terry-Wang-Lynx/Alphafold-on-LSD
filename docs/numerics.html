Mathematical and numerical contracts.

Objective semantics

Distances are in Å. Bins are [0,e0), [e0,e1), …, [e_last,∞). Native boundaries must agree with the declared target boundaries. The overflow bin has no invented finite center.

Pair masks are nonnegative weights. The caller chooses directed or undirected counting; no symmetry is added. Padding is excluded. An empty effective mask or infeasible top-k selection produces an explicit invalid objective instead of a zero score.

distribution computes masked cross-entropy. interval minimizes negative log probability of selected distance bins; exclude=True uses their complement. contained selects bins entirely inside the interval; overlap includes intersecting bins. Neither resolves unknown within-bin distances. contact optimizes all eligible pairs or a fixed number of best partners per row. Contact probability is not physical binding energy.

Gradient boundaries

Hard straight-through gradients differentiate a local continuous surrogate. Ordinary finite differences of an argmax sequence are not a test of that surrogate. AF3's default Hard Atom mode uses a discrete atom carrier, soft sequence feature injection, and declared template/recycle detachment. In Soft Atom mode, shared sequence probabilities drive the query and reference-atom encoder during gradient updates. AF3 diffusion and confidence remain forward-only.

AF2 computes the gradient through the last recycle; preceding recycle states are detached. Its default consistent scoring uses the final gradient graph even for score-only calls. The default scalar guard compares the final objective against an independent forward graph with matched state and key. This guard is not a certificate of gradient accuracy.

Full-chain sampled atom gradients

In atom_mode="soft_sampled", the training objective is the expectation of the loss with soft token inputs and native atomic inputs from a random sequence drawn from those token probabilities. With probabilities p, draw S, and per-draw objective L, the gradient is the expectation of grad L + L * grad log P(S). The first term holds the sampled atomic layout fixed. The second changes its probability, using the mean loss of the other independent draws as a variance-reduction baseline. A finite difference with redrawn sequences measures jumps in an individual Monte Carlo realization. Use exhaustive expectations on a small oracle, or differentiate the frozen draws with importance reweighting for a fixed-sample check. Argmax endpoints use a single native layout.

Precision and state

Design logits and returned gradients use float32. Host-side optimizer norms, moments and update arithmetic use float64 before explicit conversion back to float32. The default matrix-multiply policy is highest; AF2 disables bfloat16 activations by default, and AF3 configures its trunk accordingly. These settings do not make all weights, kernels or model operations float64 or uniformly float32.

Runtime choices and source fingerprints participate in checkpoint identity. Changing a dependency, source file or objective can invalidate restoration. Do not bypass identity checks to claim reproduction.

Software checks

The distributed suite uses synthetic tensors and mock backends for analytic loss/gradient checks, masks, token mapping, numerical failures, optimizer arithmetic, source identity and recovery. Native models and GPU kernels require their own runtime checks; CPU tests alone do not verify them. The numerics module exposes reusable comparison gates with explicitly chosen tolerances.
