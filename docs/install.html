Install the library and model runtimes.

Core library

The core API requires Python ≥3.10 and NumPy. Differentiable objectives and the toy require JAX. Native model profiles below target Linux x86_64, Python 3.12 and CUDA 12; the package metadata alone does not certify every runtime or GPU combination.

python3 -m venv .venv
.venv/bin/python -m pip install '.[jax]'
.venv/bin/hallulab doctor

AF2 in a separate environment

Run from the source root. The hash-pinned dependency files target the stated Linux platform. ColabDesign source is installed separately from an immutable revision; model parameters must already be available locally.

python3.12 -m venv .venv-af2
.venv-af2/bin/python -m pip install --only-binary=:all: --require-hashes   -r environments/af2-py312-build-lock.txt -r environments/af2-py312-cu12-lock.txt
.venv-af2/bin/python -m pip install --no-deps --no-build-isolation   'colabdesign @ git+https://github.com/sokrypton/ColabDesign.git@e31a56fe1d9b4de25c8697f3a28b75892941cc72'
.venv-af2/bin/python -m pip install --no-deps --no-build-isolation .
.venv-af2/bin/python environments/verify_af2_source.py
.venv-af2/bin/python -m pip check

Before importing JAX, select an available GPU and use the profile environment settings. Obtain parameters through the official AlphaFold distribution. The tool does not download them.

export CUDA_VISIBLE_DEVICES=YOUR_AVAILABLE_GPU_UUID
export XLA_PYTHON_CLIENT_PREALLOCATE=false
export XLA_FLAGS=--xla_gpu_enable_triton_gemm=false
export JAX_ENABLE_X64=false
.venv-af2/bin/hallulab doctor --runtime af2 --require-gpu   --weights /path/to/af2/parameters --profile environments/af2-py312-runtime.json

AF3 runtime and native source

Use separate runtime and build environments. A native C++ compiler and the upstream build dependencies are required. Model weights and CCD data are not in this distribution. Follow the pinned upstream installation instructions for platform prerequisites.

python3.12 -m venv .venv-af3
.venv-af3/bin/python -m pip install -r environments/af3-cu12-requirements.txt
python3.12 -m venv .venv-af3-build
.venv-af3-build/bin/python -m pip install -r environments/af3-build-requirements.txt
git clone https://github.com/google-deepmind/alphafold3.git external-af3
git -C external-af3 checkout b2f3d45fbfcacc5183bd5345d15df93571b8437f
SETUPTOOLS_SCM_PRETEND_VERSION=3.0.4.dev2+gb2f3d45fb CMAKE_BUILD_PARALLEL_LEVEL=4 CMAKE_ARGS=-DBUILD_TESTING=OFF   .venv-af3-build/bin/python -m build --wheel --no-isolation external-af3
.venv-af3/bin/python -m pip install --no-deps external-af3/dist/*.whl
.venv-af3/bin/python -m pip install --no-deps .
.venv-af3/bin/python -m pip check

Prepare CCD before the first AF3 run

The pinned upstream data builder requires an uncompressed components.cif. Run the following from the source root on Linux, with curl, gzip and sha256sum installed. Stop if a command fails. The download is the public wwPDB CCD; model weights are obtained separately.

mkdir -p model-data/ccd
curl --fail --location --retry 3 --output model-data/ccd/components.cif.gz https://files.wwpdb.org/pub/pdb/data/monomers/components.cif.gz
gzip -t model-data/ccd/components.cif.gz
gzip -dc model-data/ccd/components.cif.gz > model-data/ccd/components.cif
export LIBCIFPP_DATA_DIR="$PWD/model-data/ccd"
sha256sum model-data/ccd/components.cif.gz model-data/ccd/components.cif > model-data/ccd/SHA256SUMS
date -u +%Y-%m-%dT%H:%M:%SZ > model-data/ccd/retrieved-utc.txt
.venv-af3/bin/build_data

For an offline installation, place your retained components.cif in that directory, verify its previously recorded checksum, set LIBCIFPP_DATA_DIR, then run build_data. The public CCD changes over time: retain the downloaded file, retrieval date and checksums with your environment. Do not silently borrow another Python environment's compiled modules or data.

export CUDA_VISIBLE_DEVICES=YOUR_AVAILABLE_GPU_UUID
export XLA_PYTHON_CLIENT_PREALLOCATE=false
export XLA_FLAGS=--xla_gpu_enable_triton_gemm=false
.venv-af3/bin/hallulab doctor --runtime af3 --require-gpu   --weights /path/to/af3/models --profile environments/af3-runtime.json

doctor checks explicitly requested imports, package versions, devices and parameter-file presence. It does not load all parameters, execute a model, or certify numerical correctness. Keep the profile, package versions, model source revision and input data identity with each run.
